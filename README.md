# Python ATM Simulation

A command-line ATM Simulation application built in Python that replicates core banking operations.

## Features
- Secure PIN authentication
- Balance inquiry
- Cash deposit and withdrawal with validation
- Clean, menu-driven CLI interface

## How to Run
1. Clone the repository:
   git clone https://github.com/mutahirnadeem126-gif/python-atm-simulation.git
2. Run the Python script:
   python atm_simulation.py
